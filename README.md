# Aarunya Portfolio

Standalone creative portfolio for Aarunya Web Solutions, built with static HTML, CSS and JavaScript. No framework or build step is required.

## Preview locally
Open `index.html` in a browser. Vercel is connected to this repository and will deploy commits from `main`.

## Design direction
- Premium dark editorial interface with Aarunya orange `#F47721`, blue `#2474DF`, and navy `#172238`.
- Work areas: web, software/SaaS, creative design and performance marketing.
- CSS art direction and interface mockups are illustrative visual framing, not actual client screenshots or performance claims.
- No replacement logo or custom logo SVG is included. The wordmark is temporary text and should be paired with the owner's approved logo when supplied.
- No invented performance metrics, testimonials, or client endorsements.
- Responsive layout, reduced-motion support, and A4 print CSS.

## Assets to add
Create `assets/brand/`, `assets/work/web/`, `assets/work/products/`, `assets/work/creative/`, `assets/work/ads/`, and `assets/work/video/`. Add approved original files only. Use meaningful lowercase filenames, e.g. `billzen-dashboard.webp`. Replace illustrative CSS mockups with real screenshots after review.

## PDF brochure
Open the deployed site in a browser and choose Print / Save as PDF. Choose A4 and enable background graphics if offered.
